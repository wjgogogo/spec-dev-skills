# 视觉方向的探索与收敛

用于视觉方向尚不明确的设计任务。局部修复沿用既有风格；只读评审只分析与建议。以下步骤按当前不确定性选用。

## 1. 明确方向与判断标准

- 从产品用途、品牌含义和希望传达的感受中寻找视觉线索，把“有趣”“专业”等词落实到可观察的排版、配色或图形选择。视觉主题应帮助理解产品。
- 先固定代表性的真实内容、主要操作、目标宽度和既有约束。后续比较围绕任务发现性、可读性、品牌契合度和整体一致性。

## 2. 收集并拆解参考

- 优先查看现有产品和品牌资产，再按需要观察外部界面。说明借鉴的是哪种关系，例如标题与操作的层级、插画与内容的联系、区块之间的过渡。
- 从多个参考中组合适合当前任务的做法，保留有用的局部线索。参考较弱的方案也可能包含可复用的按钮、构图或配色思路。

## 3. 用少量原型探索差异

- 先选能代表方向的一个页面或区域。营销页可以从首屏切入，应用界面从核心任务区域切入；避免同时生成整套产品。
- 按尚未解决的设计问题生成一小批明显不同的候选，例如克制、适中、较有表现力。需要突破当前思路时，可留一个更自由的方向；已有有效方向时无需继续增加版本。
- 保持内容、功能和比较宽度一致，让差异集中在待探索的维度。多个方向都不成立时，回查概念与任务的关系，再决定下一轮试验。

## 4. 并排比较与局部打磨

- 保留比较基线，复制候选并每次调整少量因素。在同一内容、宽度和状态下并排观察，说明哪项变化改善了任务和视觉关系。
- 使用成本最低、符合当前技术栈的原型方式。独立静态探索可用单个 HTML；已有应用优先复用现有预览、组件和样式。
- 配色、字号或位置需要反复微调时，可利用现有工具或临时制作简单的实时调节面板。选定后将数值落实到项目 token 或组件，试验控件留在原型中。
- 保留仍有比较价值的候选及关键选择理由即可；探索记录的规模应与任务相称。

## 5. 从局部延伸到整体

- 将选定区域中的字体、颜色、间距和图形语言用于相邻内容，逐步扩展。检查插画、背景、导航与区块过渡是否连贯，孤立好看的素材也需要放回页面判断。
- 根据实际任务决定是否采用动画、动态导航或装饰。先保证阅读顺序、操作发现性和相关状态，再细化表现。
- 方向确定后收敛到少量组件和 token，进入项目正常实现与验证流程。

## 6. 判断何时结束探索

核心任务清楚、视觉语言一致，且相关宽度和状态下没有明显问题时，进入交付。后续迭代应针对可指出的问题；已有可用方案且新候选没有明确收益时，保留当前选择。受条件限制未完成的视觉检查如实报告。
